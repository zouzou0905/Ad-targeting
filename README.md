# Amazon 关键词 ASIN 广告位置检测工具

这个工具读取 Excel 中的“关键词”和“ASIN”，逐个打开 Amazon 搜索页，检查目标 ASIN 的广告排名、自然排名、网格外广告位、页面总位置和出现页码。当前核对阶段只输出实时日志，不生成或修改任何 Excel 文件。

## 已适配当前表格

- 识别合并单元格中的关键词和广告活动。
- 同一关键词可对应任意数量的 ASIN，不限于 2–3 个。
- 重复关键词只搜索一次，再把结果对应到所有活动行。
- 同一 ASIN 同时出现广告位和自然位时，两种位置都会记录；若同时出现在网格外广告模块，也会分别记录。
- 商品顺位只统计搜索网格里“一排多个”的商品位，轮播位、推荐位不参与顺位编号。
- 固定扫描每个关键词前 3 页。即使目标 ASIN 已在第 1 页出现，也会继续扫描第 2、3 页，以同时捕获广告位、自然位和网格外广告位。
- 遇到 Amazon 验证码时暂停，等待人工完成后继续。
- Amazon 首页或搜索页遇到临时网络错误、`ERR_FAILED` 或服务器 `5xx` 时会自动重试三次；如果首页仍失败，会保留浏览器供手动打开，不会立即关闭程序。
- 页面会以约 70% 屏幕高度逐段慢速滚动，并在到底后等待内容连续两次不再变化，降低懒加载商品漏扫的概率。
- 每页日志会同时显示计入位置数、广告/自然数、网格外广告模块数、标准搜索结果数、唯一 `data-asin` 数、商品链接唯一 ASIN 数以及加载是否稳定，便于判断页面模块是否完整加载。
- 运行日志最后会把所有“有位置”的关键词和 ASIN 单独集中列出，便于人工核对。

## 使用方法

1. 双击 `运行亚马逊广告位检测.cmd`。
2. 按提示确认 Excel 路径、Amazon 站点、间隔秒数和本次扫描的关键词数量。每个关键词固定扫描 3 页；核对阶段默认先扫描 3 个唯一关键词，输入 `0` 才会扫描全部。
3. Chrome 打开后，先确认站点、配送邮编和登录状态，再回到命令窗口按 Enter。
4. 扫描期间，窗口会实时显示每个 ASIN 的广告位、自然位、网格外广告位、页码和总位置。
5. 完成后会在工具目录的 `logs` 文件夹保存一份可读 `.txt` 日志和一份原始 `.json` 日志，不会写入表格。

建议保持可见浏览器模式，并使用至少 3–5 秒的关键词间隔。搜索结果会受到站点、邮编、登录状态、时间和个性化影响。

## 日志内容

- `广告排名（首个）`：该 ASIN 在已扫描范围内作为 Sponsored 商品的首次广告顺位。
- `广告排名（全部）`：同一 ASIN 多次作为广告出现时的全部广告顺位。
- `自然排名（首个）`、`自然排名（全部）`：对应非 Sponsored 商品结果。
- `页面总位置（全部）`：搜索网格内广告位和自然位混合后的商品卡片位置。
- `首次出现页`、`页内商品位`：首次出现所在页及该页内顺位。
- `网格外广告位`：该 ASIN 出现在搜索网格之外的独立广告模块中。日志会标注模块类型（视频广告／精选商品广告／横幅广告／品牌广告）以及它位于第几个搜索结果之后。这类广告不占用搜索顺位编号。
- 每页广告/自然商品数量：用于核对 Sponsored 标记的识别结果。
- 每页加载诊断：`标准结果`、`可见唯一 ASIN`、`商品链接唯一 ASIN` 三项可用于判断 Amazon 当次实际返回了多少个可定位商品；`网格外广告模块` 显示该页识别到的网格外广告模块数量。它们不一定等于肉眼看到的所有格子数。
- 广告识别依据：显示工具根据哪个 Sponsored 标签或页面属性判断为广告。
- 日志末尾的“有位置的关键词和 ASIN 汇总”：集中显示至少命中一次广告位、自然位或网格外广告位的组合。

## 注意事项

- Amazon 页面结构可能调整。如果整页都提示“未识别到商品卡片”，或网格外广告位长期识别为 0，需要更新 `amazon_scanner.mjs` 中的选择器（网格卡片与广告标记两处）。
- 商品顺位只统计**主搜索网格**中的商品卡片（`data-component-type="s-search-result"`），也就是搜索结果里一排多个的那种商品位。轮播位、推荐位不计入顺位，因此日志中的位置数与页面上真正的搜索网格商品数一致。
- 广告分两类记录：网格内卡片上的广告计入“广告排名”；网格外独立广告模块（视频广告、精选商品广告、横幅广告、品牌广告等）单独记为“网格外广告位”，只标注出现在第几页、位于第几个搜索结果之后，不占用搜索顺位编号。
- 网格外广告模块需要能从模块内解析出 ASIN 才会被记录。没有 ASIN 的纯展示型广告模块无法对应到目标 ASIN，不会出现在日志里，因此页面视觉上的格子数可能大于日志中的可定位商品数。
- 请遵守 Amazon 适用条款，避免高频运行或并发扫描。
